# 百鬼めくり

めくって、そろえて、百鬼を祓え。

スマホ縦画面の札合わせローグライク。ブラウザでそのまま遊べます。スマホではホーム画面に追加すると、ブラウザのバーなしで遊べます。

**遊ぶ：https://kome0824.github.io/hyakki-mekuri/**

## 遊び方

- 札をタップすると開く。順番待ちはなし、どんどんめくれる（同時に開けるのは3枚まで）。
- 開いている札に同じ札が2枚そろうと、その場で技が出る。
- 続けてそろえると「連」が増えて技が強くなる。8連で「百鬼夜行」：しばらく全部の札が見えて威力が上がる。
- 盤面の上の帯で、敵の次の行動・敵のHP・攻撃までの時間・自分のHPが分かる。
- マップを進み、各幕の一番上の「幕の主」を祓うと次の幕へ。三幕を越えると夜明け。
- 力尽きても経験がたまり、新しい札やお守りが解放される。
- 「果てなき夜」はエンドレス。第3幕のあとも幕が続き、一周ごとに敵が強くなる。
- 「図鑑」で札の効果、集めたお守り、出会った妖怪（HP・行動の順番）を見られる。まだのものは ？？？。
- 「記録」で成績を見られる。「結果を共有」で、めくり熱や称号の入った結果の画像を付けてシェアできる（スマホは共有メニューから X・LINE・Discord などへ。PCでは画像を保存して文章をコピー）。
- 記録の画面の「データを全部消す」で、確認のあと、記録・解放・図鑑・設定を全部消して最初からやり直せる。

## PCで遊ぶ

キーボードだけで遊べます。

- 札：盤面の4×4と同じ並びのキー。配置は3つから選べる
  - 左手：1〜4・Q〜R・A〜F・Z〜V
  - 右手：7〜0・U〜P・J〜;・M〜/
  - 両手：3 4 8 9・E R U I・D F J K・C V M ,（左2列を左手、右2列を右手）
- 画面の操作：↑↓で選んで Enter、Esc でもどる・一時停止
- タイトル右上の「操作」で、端末（自動／PC／スマホ）とキー配置を設定できる
- PCのときは伏せ札の真ん中にそのキーが大きく出るので、見えている文字を押せばよい

くわしくはゲームのタイトル画面の「遊び方」「図鑑」へ。
